Sobre el proyecto

Este proyecto proporciona un Sistema creado para la implementación del próximo Cablebus que será instalado en la ciudad. El sistema esta dividido en dos partes; la primera, un sistema de recorridos y traslados que menciona dentro de un mapa el recorrido indicado que marcara cada estación del cablebus, donde se visualizan:

  • Mapeo de traslados de cada estación
  • Numero de unidad
  • Llegada a la base
  • Velocidad en que se traslada entre estaciones

    La segunda parte se basa en un Sistema de alerta de robo dentro de cada estación del cablebus, donde en cada registro de emergencia un operador utiliza el sistema para detectar le ubicación del dispositivo por medio del usuario registrado, maneja la captura de áreas de cámaras de vigilancia asi como una asistencia remota de una unidad de policía hacia la ubicación detectada.
